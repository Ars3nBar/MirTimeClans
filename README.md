# ⚔️ MirTimeClans v1.0.0

**Полноценная клановая система с иерархией ролей, клановой базой и поддержкой PlaceholderAPI** для серверов Minecraft (**Paper / Purpur 1.21+**), разработанная для проекта **Mir-Time**.

---

## 🌟 Основные возможности

### 1. Создание и управление кланом (`/clan`)
* Создание собственного клана с уникальным названием и цветным тегом (полная поддержка HEX-цветов формата `&#0055ff`).
* Гибкая система ролей и прав внутри объединения: **Лидер**, **Заместитель**, **Модератор** и **Участник**.
* Приглашение игроков в клан с подтверждением через интерактивные кликабельные кнопки в чате (`[Принять]` / `[Отклонить]`).
* Просмотр подробной статистики клана, списка участников в сети и даты создания через `/clan info`.

### 2. Клановая база и PvP-защита
* **Clan PvP (`/clan pvp`):** переключаемый режим огня по союзникам, защищающий участников одного клана от случайного урона в массовых сражениях.
* **Точка дома клана (`/clan home`):** общая точка телепортации для всех участников с настраиваемой задержкой и отменой при движении или получении урона.

### 3. Интеграция с PlaceholderAPI
Встроенные плейсхолдеры для красивого вывода информации о клане в таб-лист, скорборд и глобальный чат:
* `%mirtimeclans_name%` — полное название клана игрока.
* `%mirtimeclans_tag%` — отформатированный цветной тег клана (возвращает пустоту, если игрок не состоит в клане).
* `%mirtimeclans_role%` — текущая роль игрока внутри клана.
* `%mirtimeclans_members%` — счётчик участников онлайн / всего в клане.

## ⌨️ Команды и права (Permissions)

| Команда | Алиасы | Описание | Право |
| :--- | :--- | :--- | :--- |
| `/clan create <тег> <название>` | `/c create` | Создать новый клан | `mirtime.clans.create` |
| `/clan info [клан]` | `/c info` | Посмотреть информацию и состав клана | `mirtime.clans.use` |
| `/clan invite <ник>` | `/c invite` | Пригласить игрока в клан | `mirtime.clans.use` |
| `/clan kick <ник>` | `/c kick` | Исключить участника из клана | `mirtime.clans.use` |
| `/clan promote <ник>` | `/c promote` | Повысить ранг участника клана | `mirtime.clans.use` |
| `/clan demote <ник>` | `/c demote` | Понизить ранг участника клана | `mirtime.clans.use` |
| `/clan leave` | `/c leave` | Покинуть текущий клан | `mirtime.clans.use` |
| `/clan disband` | `/c disband` | Расформировать клан (только лидер) | `mirtime.clans.use` |
| `/clan sethome` | `/c sethome` | Установить общую точку дома клана | `mirtime.clans.sethome` |
| `/clan home` | `/c home` | Телепортироваться на базу клана | `mirtime.clans.home` |
| `/clan pvp` | `/c pvp` | Включить или выключить урон по союзникам | `mirtime.clans.use` |
| `/clan reload` | — | Перезагрузить `config.yml` без рестарта | `mirtime.clans.admin` |

### Дополнительные права
* `mirtime.clans.admin` — доступ ко всем административным командам управления и удаления чужих кланов.
* `mirtime.clans.color` — разрешение на использование HEX-градиентов в теге клана.

## 📦 Установка

1. **Скачайте плагин из раздела Releases:**
   * Перейдите во вкладку **[Releases](../../releases)** в правой части страницы репозитория.
   * Выберите последний стабильный выпуск (например, `v1.0.0`).
   * В блоке **Assets** нажмите на файл `MirTimeClans-1.0.0.jar`, чтобы скачать его.
2. **Установите на сервер:**
   * Загрузите скачанный `.jar`-файл в папку `/plugins/` вашего сервера (**Paper / Purpur 1.21+**).
   * *(Рекомендуется)* Установите **PlaceholderAPI** для вывода клановых тегов в чат, таб-лист и скорборд.
3. **Запустите и настройте:**
   * Перезапустите сервер, настройте максимальное количество участников, длину тега и оформление сообщений в `plugins/MirTimeClans/config.yml` и выполните `/clan reload`.
