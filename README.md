# 🛡️ MirTimeClans v1.0.0

**Многофункциональная клановая система с современным GUI-интерфейсом, общей казной, клановым домом и защитой от огня по своим** для серверов Minecraft (**Paper / Purpur 1.21+**).

---

## 🌟 Основные возможности

* **Интуитивное GUI-меню (`/clan`):** управление составом, просмотр статистики клана, телепортация на клановую базу и управление банком в одном окне без запоминания сложных команд.
* **Клановая казна (интеграция с Vault):** участники могут пополнять общий бюджет клана (`/clan deposit <сумма>`), а лидер — снимать средства на развитие и ивенты (`/clan withdraw <сумма>`).
* **Клановый дом (`/clan sethome` / `/clan home`):** общая точка телепортации для всех участников клана с защитой от использования в бою.
* **Приватный клановый чат (`/c <сообщение>`):** быстрое общение только между участниками вашего клана с красивым форматированием.
* **Отключение Friendly-Fire:** автоматическая блокировка урона между соклановцами (включая ближний бой, стрелы и трезубцы) для комфортных командных PvP-сражений.
* **Интеграция с PlaceholderAPI:** вывод тега клана в таб-лист, скорборд и глобальный чат (например, `%mirtimeclans_tag%`).
* **Надёжное хранение данных:** автоматическое сохранение всех кланов, балансов и координат баз в локальный файл `clans.yml` без потерь при рестартах.

## ⌨️ Команды и права (Permissions)

| Команда | Описание | Доступ |
| :--- | :--- | :--- |
| `/clan` | Открыть главное GUI-меню управления кланом | Все игроки |
| `/clan create <тег>` | Создать новый клан (с проверкой стоимости создания) | Все игроки |
| `/clan disband` | Распустить клан навсегда | Только Лидер |
| `/clan invite <ник>` | Отправить приглашение в клан | Лидер / Офицер |
| `/clan accept` | Принять приглашение в клан | Все игроки |
| `/clan kick <ник>` | Исключить участника из клана | Лидер / Офицер |
| `/clan leave` | Покинуть текущий клан | Участники |
| `/clan sethome` | Установить общую точку дома клана | Лидер |
| `/clan home` | Телепортироваться на базу клана | Все участники |
| `/clan deposit <сумма>` | Положить валюту в казну клана | Все участники |
| `/clan withdraw <сумма>` | Снять валюту из казны клана | Только Лидер |
| `/c <сообщение>` | Отправить сообщение в чат клана | Все участники |

### Административные права
* `mirtime.clans.admin` — доступ к перезагрузке конфигурации и управлению кланами.

## 📦 Установка
1. Скачайте `MirTimeClans-1.0.0.jar` из вкладки **Actions**.
2. Установите зависимости **Vault** и **PlaceholderAPI** (опционально для плейсхолдеров).
3. Поместите файл в папку `plugins/` и перезапустите сервер.
4. Настройте стоимость создания клана, лимит участников и оформление в `plugins/MirTimeClans/config.yml`.
